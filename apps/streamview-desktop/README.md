# StreamView Windows Desktop

This directory contains the Tauri desktop shell used by the Windows Lite release.

The desktop shell reuses `apps/streamview-web/public` for the frontend and starts
the Node backend as a bundled child process. The backend then calls the bundled
`streamview.exe` and `ffmpeg.exe`.

## Local development

Install Rust, Node.js, and the Tauri prerequisites for your platform. Build the
C++ CLI first:

```bash
cmake -S ../.. -B ../../build
cmake --build ../../build --parallel
npm ci
npx tauri dev
```

For a release build, the GitHub Actions workflow stages `streamview.exe`,
FFmpeg, Node, and the Web frontend under `src-tauri/resources` before running:

```bash
npx tauri build --ci
```

Do not commit files under `src-tauri/resources`; they are platform-specific
release inputs generated by CI.
